# Presets

Value-list shortcuts for Airtable's enum-like strings, so field types and choice colors aren't typed by hand. Each is a Grasshopper value list: pick an item and wire its output into the matching input.

| Component | Description |
|---|---|
| [Airtable Color](AirtableColorPreset.md) | Airtable's 40 fixed select-choice colors, for [Build Select Choices](../Field/SelectFieldOptions.md). |
| [Field Type](FieldTypePreset.md) | 14 writable field types, for [Build Field JSON](../Field/FieldJson.md). |
