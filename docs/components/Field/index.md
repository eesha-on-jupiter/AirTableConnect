# Field

Build field definitions (including select choices and their colors) and add or change fields on an existing table.

| Component | Description |
|---|---|
| [Build Field JSON](FieldJson.md) | Assembles a field name, type, description and options into Field JSON. No network call. |
| [Build Select Choices](SelectFieldOptions.md) | Pairs choice labels with Airtable colors into Options JSON for a select field. No network call. |
| [Create Field](CreateField.md) | Adds a field to an existing table from Field JSON. Button-triggered. |
| [Update Field](UpdateField.md) | Changes an existing field's name, description or options. Button-triggered. |

Field types and choice colors come from the [Presets tab](../Presets/index.md).
