# Auth

Checks a personal access token against Airtable before anything else is wired. Runs on every solve; it reads, never writes.

| Component | Description |
|---|---|
| [Connect to Airtable](AirTableConnectAuth.md) | Verifies a personal access token and returns the connected user's ID. |

See [Authentication](../../authentication.md) for creating the token and choosing scopes.
