# Table

Build a table's schema locally, then create it in a base with a button click.

| Component | Description |
|---|---|
| [Build Table JSON](TableJson.md) | Assembles a table name, description and Field JSON list into Table JSON. No network call. |
| [Create Table Layout](CreateTable.md) | Creates a new table in a base from Table JSON. Button-triggered. |

Columns come from [Build Field JSON](../Field/FieldJson.md) on the [Field tab](../Field/index.md).
