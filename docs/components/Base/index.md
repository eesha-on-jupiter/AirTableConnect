# Base

Read-only lookups that turn bases and tables into names and IDs on the canvas, so nothing has to be copied from the Airtable web UI. Both run on every solve.

| Component | Description |
|---|---|
| [List Bases](GetBases.md) | Lists the bases the token can access, as names and IDs. |
| [Get Base Schema](GetBaseSchema.md) | Lists the tables in a base, as names and IDs. |
