AirTableConnect turns a Grasshopper canvas into a live editor for Airtable bases.

- Check an Airtable token works before wiring anything else - [demo 01](../demos/README.md#01---connect)
- Browse the bases and tables a token can see without leaving Grasshopper - [demo 02](../demos/README.md#02---discover-the-schema)
- Scaffold a new table with typed columns and color-coded select choices from a Grasshopper-defined schema - [demo 03](../demos/README.md#03---create-a-table-layout)
- Push a schedule, room list or cost breakdown computed in Grasshopper into Airtable as rows in one click - [demo 04](../demos/README.md#04---push-parametric-data)
- Drive geometry from an Airtable table, one record per item - [demo 05](../demos/README.md#05---drive-generation-from-airtable)
- Write analysis results back to their records, or keep a table in sync with a live model by a key field - [demo 06](../demos/README.md#06---write-back-and-sync)
- Attach images to records from a URL, a file on disk or a live bitmap - [demo 07](../demos/README.md#07---attach-pictures)
